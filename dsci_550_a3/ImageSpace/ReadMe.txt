This is our complementary pipeline using Python scripts, OpenCV-based k-means clustering, and an Elasticsearch backend to overcome setup constraints posed by legacy ImageSpace dependencies. We clustered the 1000 images into three groups (k=3), chosen to balance interpretability with meaningful visual differentiation across the dataset. These clusters revealed structural themes and lighting consistencies not captured by raw feature vectors alone. The assigned clusters were visualized using bar plots, and the top-5 nearest neighbors per query image were displayed to validate the internal coherence of each group. Image metadata and cluster labels were indexed in Elasticsearch, replicating similarity retrieval functionality without direct use of ImageCat outputs. This dual-track strategy highlighted both the challenges and the adaptability required in visual search projects, demonstrating the value of hybrid methods for image understanding.
